1. PROJECT OVERVIEW
================================================================================

QuickDash Customer App is a comprehensive multi-service mobile application 
built with Flutter that provides various on-demand services including:
- Food Delivery (E-commerce)
- Cab/Taxi Services
- Parcel Delivery
- Rental Services
- On-Demand Services (Provider-based services)

The app serves as a unified platform where customers can access multiple 
service types from a single interface, with integrated payment gateways, 
real-time tracking, and comprehensive order management.

4.1 LOCATION SERVICES IMPLEMENTATION
------------------------------------

4.1.1 Location Fetching Algorithm:
The app uses a multi-layered approach for location services:

Primary Service: Geolocator Package
- Location: lib/services/helper.dart
- Function: getCurrentLocation()
- Implementation:
  * Checks if location services are enabled
  * Requests location permissions (denied/deniedForever handling)
  * Uses LocationAccuracy.high for precise coordinates
  * Returns Position object with latitude/longitude

Secondary Service: Location Package
- Used for permission status checking
- Provides location.hasPermission() and location.requestPermission()
- Handles platform-specific permission dialogs

4.1.2 Reverse Geocoding (Address from Coordinates):
- Service: Geocoding Package
- Function: placemarkFromCoordinates()
- Implementation:
  * Converts lat/long to human-readable address
  * Extracts: name, subLocality, locality, administrativeArea, 
    postalCode, country
  * Used in: EcommerceHomeScreen, location_permission_screen, 
    dine_in_screen, cab_service_screen

4.1.3 Location Permission Handling:
- Location: lib/constants.dart
- Function: checkPermission()
- Flow:
  1. Checks current permission status
  2. Requests permission if denied
  3. Shows SnackBar for denied permissions
  4. Shows PermissionDialog for permanently denied
  5. Executes callback on successful permission

4.1.4 Distance Calculation:
- Service: Geolocator Package
- Function: getKm() in constants.dart
- Algorithm: Uses distanceBetween() method
  * Calculates distance in meters
  * Converts to kilometers
  * Returns formatted string (2 decimal places)

4.1.5 Map Integration:
- Google Maps: Used for displaying maps, markers, and routes
- OSM (OpenStreetMap): Alternative map provider
- Map Type Selection: Configurable via Firebase settings
  (selectedMapType from "DriverNearBy" document)

4.1.6 Route Calculation:
- Service: Google Maps Distance Matrix API
- Location: lib/cab_service/cab_service_screen.dart
- Function: getDurationDistance()
- Implementation:
  * Uses Google Maps API endpoint
  * Calculates distance and duration between two points
  * Returns JSON with distance (meters) and duration (seconds)

- Alternative: OSRM (Open Source Routing Machine)
- Function: getDurationOsmDistance()
- Uses: http://router.project-osrm.org/route/v1/driving
- Provides route geometry and navigation instructions

4.1.7 Polyline Drawing:
- Service: Flutter Polyline Points
- Location: lib/ui/orderDetailsScreen/order_tracking_screen.dart
- Function: getDirections()
- Implementation:
  * Gets route between origin and destination
  * Converts polyline points to LatLng coordinates
  * Draws route on Google Maps
  * Updates markers for driver and destination

4.1.8 Location Usage in App:
- Home Screen: Fetches current location on init
- Service Selection: Uses location for nearby vendor/service search
- Order Tracking: Real-time driver location updates
- Cab Booking: Pickup and destination location selection
- Parcel Delivery: Sender and receiver location
- Address Management: Saves user addresses with coordinates

The app supports 11 payment gateways with a unified payment interface:

4.2.2 Stripe Payment:
- Package: flutter_stripe: ^11.1.0

  3. Calls: createStripeIntent() - creates payment intent

  5. Handles success/failure callbacks

     - _handlePaymentSuccess()

  4. Supports external wallets (Paytm, etc.)

4.2.4 PayPal Payment:

4.2.5 PayStack Payment:

4.2.6 FlutterWave Payment:

4.2.7 Paytm Payment:

4.2.8 Other Payment Gateways:

4.5 CART MANAGEMENT SYSTEM
---------------------------

4.5.1 Local Database:
- Technology: Moor Flutter (SQLite)
- Location: lib/services/localDatabase.dart
- Table: CartProducts

4.5.2 Cart Schema:
- id: Product ID (Primary Key)
- name: Product name
- photo: Product image URL
- price: Product price
- discountPrice: Discounted price
- vendorID: Vendor ID
- quantity: Item quantity
- extras_price: Add-ons price
- extras: Add-ons details (JSON)
- variant_info: Product variant (JSON)

4.5.3 Cart Operations:
- addProduct(): Adds product to cart
  * Checks for existing product
  * Validates vendor (single vendor per cart)
  * Increments quantity if exists
  * Adds add-ons and variants
  * Calculates total price

- updateProduct(): Updates cart item
- deleteProduct(): Removes item from cart
- deleteAllProducts(): Clears entire cart
- getAllCartProducts(): Retrieves all items

4.5.4 Cart Validation:
- Single vendor restriction: Cannot add products from different vendors
- Quantity validation: Minimum 1, maximum based on stock
- Price calculation: Includes base price, add-ons, variants

4.5.5 Cart State Management:
- Uses Provider pattern
- CartDatabase instance shared across app
- Real-time cart count updates
- Persists across app restarts
